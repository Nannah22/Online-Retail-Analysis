# Online-Retail-Analysis
R data cleaning, business metrics and visualization for the online Retail dataset using R.

* ### *Project Description* ###

This project involves the analysis of an online retail transaction dataset using the R programming language.
The main focus is to study customer buying trends, analyze sales performance, and visualize key business insights.

In this analysis, various R libraries are used for cleaning, transforming, and visualizing the data.

* ### *Dataset Description* ###

#### The data used is Transaction Online Retail R.xlsx, which has transactional data for an online retail store.
It includes the following key variables: ####

InvoiceNo – Unique identifier for each transaction

StockCode – Product code

Description - Product description

Quantity - Number of items bought

InvoiceDate – Date and time of the transaction

UnitPrice - Price per unit 

* ### *Tools Used* ###

-RGui / RStudio

-readxl for importing Excel data

-dplyr for data cleaning

-ggplot2 for visualization
* ### *Objectives of the Project* ###

-To preprocess and clean the online retail data set

-To identify and remove duplicate, missing, or invalid data entries.

-Calculate total sales per transaction and overall performance.

-To visualize sales trends and customer behavior

-This will help extract meaningful insights for making business decisions.

* ### *Methodology* ###

1. Importation of Data: The data was first imported into R via the read_excel() function.


2. Data Cleaning: The removal of missing values, duplicates, and negative quantities or prices.


3. Feature Engineering: Calculating the total sales and changing the format of dates.


4. Visualization: Use of bar charts, line plots, and summary tables displaying trends and distributions.

* ### *How to Run* ###

1. Download or clone this repo.


2. Open the R script in RStudio.


3. Install required packages:

        install.packages(c("readxl", "dplyr", "ggplot2"))


4. Run the code to view results.
